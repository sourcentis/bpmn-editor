@sourcentis/bpmn-editor — examples

Three self-contained demo pages, no backend involved — each resolves @maxgraph/core from a CDN via an import map and @sourcentis/bpmn-editor from ../dist/bpmn-editor.js.

  • Editor

    Full editing surface, ui: 'default' — toolbar, palette, import/export, no provider/persistence.

  • Read-only viewer

    ui: 'none' + readOnly: true — canvas-only, pan/zoom, no editing.

  • Simulated backend

    provider and persistence implemented in memory — shows the two backend ports in action.
Run npm run build once at the package root before opening any demo above.
